# Startup Funding Insights Dashboard Using Microsoft Power BI

## Project Overview
The Startup Funding Insights Dashboard is a data analytics project developed using Microsoft Power BI to explore startup funding trends and investment patterns. It aims to present funding information through interactive visualizations and help users understand how funding varies across startups, industries, locations, and time.

## Objectives
- Analyze startup funding trends.
- Explore funding distribution across industries and locations.
- Identify startups receiving significant funding.
- Understand investment patterns over time.
- Present insights through interactive dashboards.

## Tools and Technologies
- Microsoft Power BI Desktop
- Power Query
- Microsoft Excel
- Data Cleaning and Transformation
- Data Visualization

## Dashboard Features
The dashboard can include the following analyses, depending on the visuals implemented:
- Total Funding Analysis
- Startup Funding by Industry
- Funding Distribution by Location
- Funding Trends Over Time
- Top Funded Startups
- Interactive Filters and Slicers

## Project Workflow
1. Import the startup funding dataset.
2. Clean and transform the data using Power Query.
3. Prepare the required fields for analysis.
4. Create visualizations and KPI cards in Power BI.
5. Develop an interactive dashboard to explore funding patterns.

## Key Learnings
- Data cleaning and transformation
- Exploratory data analysis
- KPI and dashboard development
- Business insights through data visualization
- Interactive reporting using Power BI
